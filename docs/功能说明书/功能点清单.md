## 疑点核实结论

### 1. 报告导出格式

- 当前报告导出仅支持 HTML；Playwright PDF 转换、前端 PDF 按钮、历史版本 PDF 下载和相关特性开关均已移除。
- 对话指令通过 `export_report(format=html)` 导出，回复消息下方展示"下载 HTML 报告"按钮。

### 2. HomeView（/management）与 SourceConfigView（/analysis/:type/source）

- 两者均为**当前有效页面**：路由表正常注册（router/index.js），且有真实导航入口——非独立页均渲染 SidebarNav，其首项"首页"指向 /management；HomeView 的"线上/线下活动分析"卡片与 FloatingAssistant 均跳转 SourceConfigView。
- HomeView 已于 2026-07-28（f4148b0、b79297c）由演示数据看板升级为**真实使用量概览看板**：核心/辅助指标、使用趋势图（折线/柱状可切换）、机构活跃度与"导出明细"均接入 usage_dashboard 真实接口与使用事件埋点，已作为 F-SYS-03 纳入第 10 章。
- SourceConfigView 的线上数据源（OnlineSourceConfig）使用 `frontend/src/data/mockData`，后续报告页（ReportView）内容同样来自本地演示数据 store，仍属**三步分析向导的界面原型**（需求说明书 3.5 与第 7 节约束 5 明确）；向导中唯一接入真实接口的是组件编排页 SkillComposerView 的组件库（fetchSkills）。
- **章节归属结论**：SourceConfigView（及向导报告页 ReportView）不分配 3–10 章功能点编号、不单独设章，在第 2 章"系统功能总览"中以界面原型标注；HomeView 的使用量概览看板已分配 F-SYS-03；向导第 2 步的技能编排画布交互已实现且接真实接口，归入第 7 章 F-SKILL-02。

### 3. 报告版本管理（report_versions）前端可见位置

- **对话页报告卡片**（UiChatView.vue）：版本徽章"v{n}版本" + "修改历史"展开列表（版本号、动作：生成/修改、diff 摘要），数据来自会话恢复接口的 report_context.history 与 SSE report 事件。
- **运行历史页**（HistoryView.vue）：会话详情弹窗内每份报告可展开"版本(N)"，逐行列出版本徽章 v{n}、来源标签（生成/修改）、变更说明、创建时间、反馈状态（含点踩原因），并可按版本下载 HTML / PDF。
- 两处均以 `backend/src/api/routers/agent_run_history.py` 的 sessions / report 接口为数据源。
